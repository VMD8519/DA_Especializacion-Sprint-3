# Manipulación de Base de Datos Relacional 📊

En este sprint, he trabajado con una base de datos orientada a simular una situación empresarial, específicamente de una empresa dedicada a la venta de productos online. El objetivo ha sido mejorar la estructura y eficiencia de la base de datos mediante diversas manipulaciones. 
¡Aquí te cuento todo lo que hice! 😄

## Objetivos del Sprint 🎯
- El enfoque principal de este sprint ha sido:
- Manipulación de Tablas 🔨
- Realizar operaciones en tablas existentes para mejorar la organización y accesibilidad de los datos, comprendiendo su estructura y relaciones.
- Gestión de Índices 📈: Crear y optimizar índices para mejorar el rendimiento de consultas específicas en la base de datos.
- Creación de Vistas 👀: Generar vistas que simplifiquen el acceso a datos complejos y mejoren la eficiencia de las consultas.

## Actividades Realizadas 🛠️
1. Manipulación de Tablas 🗂️
2. Gestión de Índices 🔍
3. Creación de Vistas 👓

## Resultados y Aprendizajes 📈
Este sprint ha sido un excelente repaso para trabajar de forma segura y eficaz en una base de datos relacional, especialmente en el contexto de ventas online. Me ha permitido:
- Profundizar en la organización de los datos, entendiendo mejor las relaciones entre las tablas.
- Realizar consultas SQL de mayor nivel, lo que me ha ayudado a mejorar mi eficiencia y a crear soluciones más escalables y sostenibles.
